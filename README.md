# Shopify Stock Price Analysis

## Project Overview
This project analyzes Shopify stock price data using Python. It explores historical closing prices, moving averages, daily returns, and volatility to understand stock price changes over time.

## Objectives
- Visualize Shopify's historical closing price.
- Calculate 20-day and 50-day moving averages.
- Calculate daily stock returns.
- Analyze the distribution of daily returns.
- Examine stock price trends and volatility.
- Identify the period with the highest 20-day rolling volatility.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses `shopify_stock.csv`, which contains historical Shopify stock price data.

The dataset should include:
- `date` – Date of the stock observation.
- `close` – Closing stock price.

## Analysis Performed
1. Historical closing price visualization.
2. 20-day and 50-day moving average analysis.
3. Daily return calculation.
4. Daily return distribution using a histogram and KDE plot.
5. Overall stock price trend analysis.
6. Stock volatility analysis.
7. 20-day rolling volatility analysis.

## Installation
Install the required libraries using:

```bash
pip install pandas matplotlib seaborn jupyter
```

## How to Run
1. Download or clone the project.
2. Place `SHOPIFY.ipynb` and `shopify_stock.csv` in the same folder.
3. Open Jupyter Notebook.
4. Run `SHOPIFY.ipynb`.
5. Execute all cells to view the analysis and visualizations.

## Conclusion
This project helps analyze Shopify's historical stock price movements, daily returns, moving averages, and volatility using Python data analysis and visualization techniques.
